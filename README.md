# 👑 테크킹 운동회 — 설치·참여 안내서

두 팀이 휴대폰으로 겨루는 실시간 학급 미니게임입니다. 기본 팀은 **테크킹팀 vs 대니쌤팀**이고, 팀 이름·색깔·대표 이미지는 선생님 화면에서 바꿀 수 있어요. 경기는 여덟 가지예요.

| 경기 | 하는 법 | 전략 포인트 |
|---|---|---|
| 전략 줄다리기 (60초) | 줄 5개 중 하나를 골라 연타로 당겨요. 줄을 눌러 옮겨 다닐 수 있어요 | 친구들이 어느 줄에 있는지 실시간으로 보여요. 3줄을 먼저 이기면 승리 |
| 땅따먹기 (60초) | 노란 칸을 눌러 우리 팀 땅으로 만들어요 | 우리 땅과 붙은 칸만 가능, 상대 땅은 두 번 눌러야 뺏어요 |
| 이어달리기 (최대 150초) | 운동장 한 바퀴가 한 구간! [달리기]로 달리고 바통을 넘겨요 | 기다리는 친구는 [응원하기]로 주자를 빠르게 해요 |
| 거점 점령전 (90초) | 운동장을 눌러 내 캐릭터를 움직여요 | 거점 안에 우리 팀이 더 많으면 점령, 100점 먼저 |
| 판뒤집기 (45초) | 상대 팀 색 판을 눌러 우리 색으로 뒤집어요 | 끝났을 때 우리 색 판이 더 많으면 승리 |
| 단체 가위바위보 (3판 먼저) | 7초 안에 가위·바위·보를 골라요 (시간 안에는 바꿀 수 있어요) | 팀에서 가장 많이 나온 손이 팀의 손! 버튼 아래에 우리 팀 투표 수가 보여요 (상대 팀은 안 보여요) |
| 운석 피하기 (60초) | 우주 전체가 한 화면에 보여요. 경기장 안 왼쪽 아래 **조이스틱**(컴퓨터는 방향키)으로 움직여 운석을 피해요. 느린 큰 바위·보통·꼬리가 긴 빠른 운석이 섞여 날아와요 | 반짝이는 **아이템 6종**: 🛡️보호막(5초 무적) ⚡번개(5초 빨라짐) 💖단체 부활 ❄️얼음(상대 팀 2.5초 멈춤) ⭐별(+20점) 🍄꼬마버섯(6초 작아짐). 쓰러진 팀원 옆에 2초 있으면 부활! |
| 박 터트리기 (90초) | 화면을 아래로 당겼다 놓으면 주머니가 날아가요 (새총처럼) | 좌우로 흔들리는 우리 팀 박을 맞혀 게이지를 채우면 쩍! 박이 터지며 현수막이 내려와요 |

이기면 100점, 비기면 두 팀 모두 50점이 누적돼요.

### ⚖ 인원이 달라도 공평하게
한 반 인원이 홀수이거나 팀 인원이 달라도 경기마다 자동으로 보정돼요.

| 경기 | 보정 방법 |
|---|---|
| 줄다리기 | 당기는 힘을 팀 인원으로 나눠요 |
| 땅따먹기 · 판뒤집기 | 인원이 많은 팀은 1인당 쿨타임이 조금 길어져서, 팀 전체 속도가 같아요 |
| 이어달리기 | 인원이 달라도 전체 거리가 같고, 응원 보너스도 인원 비율로 계산해요 |
| 거점 점령전 | 거점 안 인원을 팀 크기 비율로 환산해서 비교해요 |
| 단체 가위바위보 | 팀에서 '가장 많이 나온 손'으로 겨뤄서 인원과 상관없어요 |
| 박 터트리기 | 인원이 적은 팀은 한 번 맞힐 때 게이지가 더 많이 차요 |
| 운석 피하기 | 모두에게 똑같은 운석이 날아오고, 살아 있는 사람 '비율'로 점수를 줘요 |

## 1. 준비물

- **서버 컴퓨터 1대**: 선생님 노트북이나 교실 PC (윈도우·맥 모두 가능)
- **학생 기기**: 휴대폰, 태블릿, 크롬북 등 인터넷 브라우저가 있으면 OK (앱 설치 필요 없음)
- **같은 와이파이**: 서버 컴퓨터와 학생 기기가 같은 네트워크에 있어야 해요
- 있으면 좋은 것: 프로젝터 (선생님 화면을 띄워 놓으면 모두가 경기 상황을 볼 수 있어요)

## 2. 서버 설치하기 (처음 한 번만)

### ① Node.js 설치
1. https://nodejs.org 에 들어가요.
2. **LTS** 버전을 내려받아 설치해요. (계속 "다음"만 눌러도 됩니다)
3. 이 게임은 Node.js 말고는 **추가로 설치할 것이 없어요.**

### ② 게임 파일 준비
받은 `techking-sportsday.zip` 파일의 **압축을 풀어요.** (압축 파일 안에서 바로 실행하면 안 돼요)

---

## 3. 서버 켜기 (수업 때마다)

### 윈도우
`시작하기(윈도우).bat` 파일을 **더블클릭**해요.

> "Windows 보안 경고 / 방화벽" 창이 뜨면 **개인 네트워크에 체크하고 [액세스 허용]** 을 눌러야 학생들이 들어올 수 있어요.

### 맥
`시작하기(맥).command` 파일을 **더블클릭**해요.

> "확인되지 않은 개발자" 경고가 뜨면 파일을 **우클릭 → 열기** 로 한 번 실행하면 다음부터는 더블클릭으로 열려요.
> "들어오는 네트워크 연결을 허용할까요?" 창이 뜨면 **허용**을 눌러요.

### 직접 실행하고 싶다면 (명령어)
압축을 푼 폴더에서 터미널(명령 프롬프트)을 열고:
```
node server.js
```

### 켜지면 이런 화면이 나와요
```
  👑 테크킹 운동회 서버가 켜졌어요!

  ▶ 학생 접속 주소 (같은 와이파이에서):
      http://192.168.0.15:3000

  ▶ 선생님 진행 화면:
      http://192.168.0.15:3000/host

  ▶ 선생님 PIN: 4821
```
- **학생 접속 주소**를 칠판에 적거나 프로젝터로 보여 주세요.
- **이 검은 창을 닫으면 서버가 꺼져요.** 수업 내내 켜 두세요.
- PIN은 켤 때마다 바뀌어요. 고정하고 싶으면 아래 "설정 바꾸기"를 보세요.

## 4. 선생님: 경기 진행하기

1. 서버 컴퓨터 브라우저에서 **선생님 진행 화면** 주소(`…/host`)를 열어요.
2. 서버 창에 나온 **PIN**을 입력해요.
3. 화면 맨 위에 학생 접속 주소가 크게 나와요. 이 화면을 프로젝터로 띄우면 좋아요.
4. 학생들이 들어오면 테크킹팀·대니쌤팀으로 **자동으로 반반** 나뉘어요.
   - 이름을 누르면 **관리 메뉴**가 열려요: 상대 팀으로 옮기기, 내보내기(한 번 더 눌러 확인). 내보낸 학생 화면에는 안내가 뜨고, 다시 참가할 수는 있어요. 팀 옮기기는 경기 중이 아닐 때만 돼요.
   - **팀 다시 섞기**: 접속한 학생들을 무작위로 다시 나눠요.
   - **나간 친구 정리**: 접속이 끊긴 학생을 명단에서 지워요.
5. 왼쪽에서 경기를 고르고 **[경기 시작]** → 3초 카운트다운 후 시작!
6. 경기가 끝나면 결과가 나오고 점수가 쌓여요. 다음 경기를 고르고 다시 **[경기 시작]**을 누르면 돼요.
   - **지금 끝내기**: 그 순간의 상황으로 승패를 정해요.
   - **점수 초기화**: 누적 점수를 0으로 되돌려요.

## 5. 학생: 참여하기

1. 휴대폰이 **선생님 컴퓨터와 같은 와이파이**에 연결되어 있는지 확인해요.
2. 브라우저(크롬, 사파리, 삼성 인터넷 등) 주소창에 선생님이 알려 준 주소를 입력해요.
   예) `192.168.0.15:3000`
3. 이름을 쓰고 **[참가하기]** → 내 팀이 나와요.
4. 선생님이 경기를 시작하면 화면이 자동으로 바뀌어요.

> 화면을 새로고침하거나 잠깐 꺼져도 **같은 이름·같은 팀으로 다시 들어가져요.**

## 6. 안 될 때 확인하기

| 증상 | 해결 방법 |
|---|---|
| 학생 화면이 아예 안 열려요 | ① 같은 와이파이인지 확인 ② 주소 끝에 `:3000` 을 붙였는지 확인 ③ 서버 창이 켜져 있는지 확인 |
| 선생님 컴퓨터에서는 되는데 학생은 안 돼요 | 방화벽이 막고 있어요. 윈도우: 제어판 → Windows Defender 방화벽 → 앱 허용 → **Node.js** 의 "개인" 체크 |
| 학교 와이파이에서만 안 돼요 | 학교 와이파이는 기기끼리 통신을 막아 두는 경우가 많아요(AP 격리). **선생님 휴대폰 핫스팟**에 노트북과 학생 기기를 함께 연결하거나, 정보 담당 선생님께 문의하세요. 아래 7번처럼 인터넷에 올리는 방법도 있어요 |
| 화면 아래에 "다시 연결하는 중…" 이 떠요 | 와이파이가 잠깐 끊긴 거예요. 자동으로 다시 연결돼요 |
| 서버 창에 "포트를 이미 쓰고 있어요" | 서버가 이미 켜져 있거나 다른 프로그램이 3000번을 쓰는 중이에요. 열린 서버 창을 닫거나 다른 포트로 켜세요 |
| 글씨체가 기본 글꼴로 보여요 | 인터넷이 안 되는 환경이에요. 게임은 정상 작동해요 |

## 7. (선택) 인터넷에 올려서 어디서든 하기

교실 밖에서도 하고 싶거나 학교 와이파이가 막혀 있다면, **Node.js를 지원하는 웹 호스팅 서비스**에 올릴 수 있어요. 이 폴더에는 `package.json`이 있어서 대부분의 서비스가 바로 알아봐요.

- 시작 명령어: `npm start` (또는 `node server.js`)
- 포트는 서비스가 정해 주는 `PORT` 값을 자동으로 사용해요.
- 환경 변수에 `HOST_PIN` 을 정해 두세요. (안 정하면 서버 기록(로그)에 PIN이 표시돼요)
- 무료 요금제는 한동안 안 쓰면 잠들었다가 첫 접속 때 깨어나느라 시간이 걸릴 수 있어요. 수업 시작 전에 미리 한 번 들어가 두세요.
- 서버를 껐다 켜면 참가자 명단과 점수가 초기화돼요.

## 8. 설정 바꾸기

**PIN·포트 고정하기**
```
윈도우(명령 프롬프트):  set "HOST_PIN=1234" && set "PORT=4000" && node server.js
맥(터미널):            HOST_PIN=1234 PORT=4000 node server.js
```

**경기 규칙 바꾸기** — `public/engine.js` 를 메모장으로 열어 숫자를 고치면 돼요.

| 바꾸고 싶은 것 | 찾을 곳 |
|---|---|
| 경기 시간 | `const DURATION = { tug: 60, land: 60, relay: 150, zone: 90, flip: 45, meteor: 60, rps: 120, bak: 90 };` |
| 줄다리기 줄 개수·옮기는 시간 | `const ROPES = 5;` `const ROPE_MOVE_MS = 800;` |
| 줄다리기 힘 소모 | `p.stamina -= ok * 2;` (숫자가 클수록 빨리 지쳐요) |
| 땅따먹기 칸 수 | `function landSize()` 안의 `10`, `12`, `14` |
| 이어달리기 전체 거리 | `Math.round(240 / legs)` |
| 거점 크기·이동 속도·목표 점수 | `const ZONE = { r: 8, speed: 1.8, goal: 100, ...` |
| 땅따먹기·판뒤집기 쿨타임 | `const LAND_COOL = 450;` `const FLIP_COOL = 300;` |
| 운석 피하기 우주 크기·이동 속도·부활 | `const METEOR = { w: 130, h: 130, pr: 2.8, speed: 30, fast: 1.6, itemR: 3.4, reviveR: 7, reviveMs: 2000, ...` |
| 운석 피하기 아이템 종류·나오는 간격 | `function makeItems` 안의 `bag` 목록과 `t += 3.5 + R() * 3` |
| 박 터트리기 목표 게이지·던지기 간격 | `const BAK = { goal: 60, throwCool: 380, ...` |
| 가위바위보 고르는 시간·승리 판 수 | `const RPS = { pickMs: 7000, revealMs: 3500, win: 3, maxRounds: 9 };` |
| 최대 인원 | `server.js` 의 `const MAX_PLAYERS = 60;` |
